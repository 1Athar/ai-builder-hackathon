# ChromePe V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a React Native Android app called ChromePe — a PhonePe-like UPI payments app with mock data, purple theme, and 9 screens covering Home, Send Money, Scan & Pay, Transaction History, Wallet, Recharge, Bills, and Profile.

**Architecture:** Tab-based navigation (5 tabs) using React Navigation; each tab owns a stack navigator for nested flows. All data is hardcoded in `src/data/mockData.ts` — no network calls. Screens are thin UI layers; shared logic lives in components and mock data.

**Tech Stack:** React Native 0.73+, TypeScript, `@react-navigation/native` + `@react-navigation/bottom-tabs` + `@react-navigation/native-stack`, `react-native-vector-icons`, `react-native-safe-area-context`, `react-native-gesture-handler`, `react-native-screens`, Jest + React Native Testing Library

import React from 'react';

  name: string;
  amount: number;

    <View style={styles.row}>
      <ContactAvatar name={name} size={40} />
      <View style={styles.info}>
        <Text style={styles.name}>{name}</Text>
        <Text style={styles.date}>{note ?? date}</Text>
      </View>
      <Text style={[styles.amount, {color: amountColor}]}>{amountText}</Text>
    </View>
  );
}

// src/navigation/AppNavigator.tsx
import React from 'react';
import {createBottomTabNavigator} from '@react-navigation/bottom-tabs';
import {createNativeStackNavigator} from '@react-navigation/native-stack';
import Icon from 'react-native-vector-icons/MaterialIcons';
import colors from '../theme/colors';

// Screens — imported lazily to avoid circular dependency
import HomeScreen from '../screens/HomeScreen';
import SendMoneyScreen from '../screens/SendMoneyScreen';
import ScanPayScreen from '../screens/ScanPayScreen';
import HistoryScreen from '../screens/HistoryScreen';
import TransactionDetailScreen from '../screens/TransactionDetailScreen';
import WalletScreen from '../screens/WalletScreen';
import RechargeScreen from '../screens/RechargeScreen';
import BillsScreen from '../screens/BillsScreen';
import ProfileScreen from '../screens/ProfileScreen';

// Stack param lists
export type HomeStackParams = {
  Home: undefined;
  SendMoney: undefined;
  Recharge: undefined;
  Bills: undefined;
};

export type HistoryStackParams = {
  History: undefined;
  TransactionDetail: {transactionId: string};
};

const HomeStack = createNativeStackNavigator<HomeStackParams>();
const HistoryStack = createNativeStackNavigator<HistoryStackParams>();
const Tab = createBottomTabNavigator();

function HomeStackNav() {
  return (
    <HomeStack.Navigator screenOptions={{headerShown: false}}>
      <HomeStack.Screen name="Home" component={HomeScreen} />
      <HomeStack.Screen name="SendMoney" component={SendMoneyScreen} options={{headerShown: true, title: 'Send Money', headerTintColor: colors.primary}} />
      <HomeStack.Screen name="Recharge" component={RechargeScreen} options={{headerShown: true, title: 'Recharge', headerTintColor: colors.primary}} />
      <HomeStack.Screen name="Bills" component={BillsScreen} options={{headerShown: true, title: 'Pay Bills', headerTintColor: colors.primary}} />
    </HomeStack.Navigator>
  );
}

function HistoryStackNav() {
  return (
    <HistoryStack.Navigator screenOptions={{headerShown: false}}>
      <HistoryStack.Screen name="History" component={HistoryScreen} />
      <HistoryStack.Screen name="TransactionDetail" component={TransactionDetailScreen} options={{headerShown: true, title: 'Details', headerTintColor: colors.primary}} />
    </HistoryStack.Navigator>
  );
}

export default function AppNavigator() {
  return (
    <Tab.Navigator
      screenOptions={({route}) => ({
        headerShown: false,
        tabBarActiveTintColor: colors.primary,
        tabBarInactiveTintColor: '#999',
        tabBarStyle: {borderTopColor: '#eee', paddingBottom: 4, height: 60},
        tabBarIcon: ({color, size}) => {
          const icons: Record<string, string> = {
            HomeTab: 'home',
            ScanTab: 'qr-code-scanner',
            HistoryTab: 'history',
            WalletTab: 'account-balance-wallet',
            ProfileTab: 'person',
          };
          return <Icon name={icons[route.name] ?? 'circle'} size={size} color={color} />;
        },
      })}>
      <Tab.Screen name="HomeTab" component={HomeStackNav} options={{title: 'Home'}} />
      <Tab.Screen name="ScanTab" component={ScanPayScreen} options={{title: 'Scan'}} />
      <Tab.Screen name="HistoryTab" component={HistoryStackNav} options={{title: 'History'}} />
      <Tab.Screen name="WalletTab" component={WalletScreen} options={{title: 'Wallet'}} />
      <Tab.Screen name="ProfileTab" component={ProfileScreen} options={{title: 'Profile'}} />
    </Tab.Navigator>
  );
}

# ChromePe

A PhonePe-inspired UPI payments Android app built with React Native (TypeScript).

## Features (V1)

- 🏠 **Home Dashboard** — balance card, quick actions, recent transactions
- 💸 **Send Money** — UPI ID / phone input, amount, success screen
- 📷 **Scan & Pay** — static QR viewfinder + manual UPI entry
- 🕐 **Transaction History** — filterable full list with detail view
- 👛 **Wallet** — linked bank accounts, add money / transfer (mock)
- 📱 **Recharge** — mobile recharge with plan selection
- 🧾 **Pay Bills** — electricity, water, gas, broadband (mock)
- 👤 **Profile** — user info, UPI ID, settings

## Prerequisites

- Node.js 18+
- Java 17 (JDK)
- Android Studio with an emulator (API 29+) **or** a physical Android device with USB debugging
- React Native CLI: `npm install -g react-native-cli`

## Setup

```bash
git clone <repo>
cd chrome-pay
npm install
```

## Run on Android

```bash
# Start Metro bundler (in a separate terminal)
npx react-native start

# In another terminal
npx react-native run-android
```

Or, if you have an emulator already open:

```bash
npx react-native run-android
```

Metro will auto-detect the connected device/emulator.

## Run Tests

```bash
npx jest --no-coverage
```

```
src/
├── components/   Reusable UI pieces
├── data/         Mock data (no backend)
├── navigation/   Tab + stack navigators
├── screens/      One file per screen
└── theme/        Color palette
```

| Tests | Jest + React Native Testing Library |
